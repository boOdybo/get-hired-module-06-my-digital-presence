# Reference Continuity — Module 05 to Module 06

Module 06 continues the fictional Maryam Ahmed case used in Module 05. This preserves a single learning journey: the learner first structures Maryam's CV, then turns the same verified university project into a portfolio entry.

## Confirmed case facts carried forward
- Maryam Ahmed — fictional recent Commerce graduate.
- Target: entry-level Operations role.
- No formal employment experience.
- University project: Sales Records Organisation.
- Used Microsoft Excel to organise sales records and prepare a summary table.
- Skills: Basic Microsoft Excel and Data Organisation.

## Facts not available in the case
- University name and project dates.
- Project file, screenshot or shareable artifact.
- Second or third project.
- Completed certifications.
- Volunteer work, writing samples or design work.
- Professional email, phone, city, LinkedIn or published portfolio URL.

These remain placeholders or are omitted. They must not be fabricated to make the portfolio appear complete.

## Learning progression
- Module 05: present background and skills in a CV.
- Module 06: demonstrate the same skills through a portfolio project description and two-page visual portfolio draft.

## Data Analysis pathway connection
The sales-records project offers a modest bridge to data analysis: organise records, describe the work clearly, and show the output. Do not claim advanced analysis, dashboards, statistical findings or quantified business impact unless the learner has actually produced them.
