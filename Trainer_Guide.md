# Module 06 — Trainer Guide

## Session focus
**Portfolio Building with Canva AI & AI Writing Tools** — formal AI Tools Session only.

**Official output:** 2-page digital portfolio draft (Canva, AI-generated descriptions).

## Continuity case
Continue with Maryam Ahmed from Module 05. Her confirmed evidence is limited to a Commerce degree, one university project organising sales records in Excel, a summary table, Basic Microsoft Excel and Data Organisation. Do not invent a second project, certificates, volunteer experience, dates, university, contact details or measurable outcomes.

## Facilitation cycle
For each practical section:
1. Explain the concept and why it matters.
2. Show a concrete example.
3. Demonstrate the tool or decision in front of learners.
4. Let learners perform the task individually or in guilds.
5. Show the resulting portfolio section.
6. Review the evidence and give feedback before moving on.

## Demonstration sequence

### A. Evidence inventory
- Ask learners to identify one real academic, volunteer, certificate, writing or design item.
- Ask what skill it demonstrates and what evidence exists.
- Distinguish confirmed facts from missing details.

### B. Project description with AI
- Preserve the source prompt exactly: `Write a 3-sentence description of a university project on [topic] that demonstrates [skill]. Use professional English.`
- Demonstrate the prompt using Maryam's known project.
- Review the generated result sentence by sentence.
- Remove invented outcomes, numbers, tools, roles or skill levels.
- The source spells the tool as `claud`; verify intended product name before the live demo.

### C. Canva AI
- Show template selection.
- Explain color scheme and contrast.
- Explain layout logic: hierarchy, alignment, spacing and consistency.
- Build two pages and insert only reviewed text.
- UI labels and AI features may vary by account; teach the decision and workflow, not button memorization.

### D. Gamma.app
- Present it as an AI-powered portfolio/presentation tool mentioned in the source.
- Do not replace the official Canva-based Portfolio Build Sprint with Gamma.

### E. Save and share
- Export PDF and open the exported file.
- Check page count, text, images and links.
- Test the online link and permissions before sharing.

## Official Portfolio Build Sprint
Participants build at least two portfolio pages using Canva and AI-generated descriptions. Trainer and peers provide real-time feedback. Award the **Portfolio Builder** badge for the first completed two-page section. Guilds vote for the most visually compelling portfolio page.

## Suggested learner task checkpoints
- Checkpoint 1: evidence inventory completed.
- Checkpoint 2: source prompt filled with a real topic and skill.
- Checkpoint 3: three-sentence project description reviewed.
- Checkpoint 4: first portfolio page designed.
- Checkpoint 5: second portfolio page designed.
- Checkpoint 6: PDF or online link checked.

## Scope boundary
Do not assess Professional Bio, LinkedIn About or Digital Audit as AI Tools outputs in this session. The source places them in Business English and Communication & Soft Skills respectively.

## Common teaching risks
- Students inventing projects to reach 2–3 projects.
- Students treating an AI-generated description as verified truth.
- Template decoration taking priority over evidence and readability.
- A public link exposing private information or failing to open for the recipient.
- Confusing a two-page minimum with a requirement to compress every section into exactly two pages.
