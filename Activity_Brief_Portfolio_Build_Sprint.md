# Activity Brief — Portfolio Build Sprint

## Official task
Build **at least two portfolio pages** using Canva and AI-generated project descriptions.

## Learning objective
Turn a real project or work sample into a concise, evidence-based portfolio entry and place it inside a clear two-page digital portfolio draft.

## Required inputs
- One real project or work sample.
- The skill demonstrated by that project.
- Any available image, document or output that can be shared safely.
- Canva access; an AI writing tool such as ChatGPT, Gemini or the tool written as `claud` in the source.

## Source prompt
```text
Write a 3-sentence description of a university project on [topic] that demonstrates [skill]. Use professional English.
```

## Work sequence
1. Identify the project and evidence.
2. Fill [topic] and [skill] in the source prompt.
3. Generate a three-sentence description.
4. Check every claim and edit unsupported content.
5. Choose a Canva template.
6. Select a color scheme and layout logic.
7. Build at least two pages following the source structure.
8. Export PDF and/or prepare an online link.
9. Receive trainer and peer feedback; make at least one improvement.

## Portfolio structure
Cover page → About me → Skills → Projects (2–3) → Certifications → Contact.

## Completion evidence
- Two or more designed pages.
- At least one reviewed AI-generated project description.
- Clear indication of missing fields rather than invented details.
- PDF or working online link.

## Badge and peer recognition
- **Portfolio Builder** badge: awarded for the first completed two-page section.
- Guilds vote for the most visually compelling portfolio page.
- Visual appeal does not override factual accuracy or readability.

## Important
Use real work only. Do not invent projects, results, certificates, roles or numbers. Do not publish private information without permission.
